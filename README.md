# מדריך ויאטנם 2026

מאגר נקודות עניין לטיול: אטרקציות, מקומות חובה, אוכל רחוב, מסעדות, שווקים,
חיי לילה, ספא ולינה — לפי תחנה, עם קישורים חיים והתאמה למזג האוויר.

## למה זה ריפו נפרד מ-`Vietnam2026`

בגלל ה-service worker. ה-worker של האתר הראשי רשום ב-scope `/Vietnam2026/`
ולכן שולט על כל מה שיושב תחתיו, כולל תת-תיקיות. הוא גם מגיש HTML ב
stale-while-revalidate, כלומר כל טעינה מציירת את הדף מהביקור הקודם.

ריפו נפרד יושב מחוץ ל-scope הזה לגמרי. ה-worker כאן מגיש HTML **רשת-קודם**,
ולכן דיפלוי חדש מגיע למכשיר בטעינה הראשונה ולא בשנייה.

בנוסף זו PWA נפרדת עם אייקון משלה, ופרסום המדריך לא נוגע בלוח המסלול.

## מקור הנתונים

התוכן נבנה ב-`Vietnam2026/kml/` — YAML לכל תחנה, גיאוקוד, ולידציה — ומיוצא
משם. **אין לערוך את `assets/poi-data.js` ידנית**; הוא תוצר.

| קובץ | מקור |
|---|---|
| `assets/poi-data.js` | `Vietnam2026/kml/out/poi-data.js` |
| `assets/climate.js` | נורמות אקלים 26/10–24/11, ממוצע 6 שנים, Open-Meteo |
| `assets/photos/` | Wikimedia Commons, רישיון חופשי. הייחוס מוצג במסך "על הטיול" |
| `index.html`, `assets/app.js` | מהתבנית `trip-template.html` דרך `build-site.ps1` |

## מה חי ומה קפוא

- **תחזית מזג אוויר** — נמשכת חיה מ-Open-Meteo בכל טעינה. ההיתכנות מחושבת
  ברגע התצוגה, ולכן שינוי בתחזית משתקף מעצמו. מעבר ל-16 יום אין תחזית,
  ואז מוצגות נורמות האקלים, מסומנות ככאלה.
- **שערי מטבע** — קבועים בקוד נכון ל-6/9/2026 (USD/ILS 3.03, USD/VND 26,016).
- **סרטונים** — שדה `video` קיים בסכימה, עדיין ריק.
